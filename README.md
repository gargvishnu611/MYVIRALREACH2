# VYBE — Music in Motion

VYBE is a GitHub-first music experience prototype combining music discovery, kinetic lyrics, 3D interaction and motion graphics.

## Included in this version

- Cinematic responsive homepage
- Interactive 3D-style album stage
- Cursor-driven depth interaction
- Kinetic lyric animation tied to the demo timeline
- Working play / pause / previous / next controls
- Seekable 30-second demo timeline
- Shuffle and track selection
- Search modal
- Mute control
- Mobile responsive layout
- No backend required for the prototype

## Run locally

Open `index.html` in a modern browser. Three.js is loaded from a CDN, so internet access is needed for the 3D library and Google Fonts.

## GitHub Pages

The repository includes a GitHub Actions workflow in `.github/workflows/pages.yml` that publishes the static site to GitHub Pages.

## Content note

The current tracks are demo placeholders and the browser-generated audio is synthetic. Before adding commercial songs or copyrighted lyrics, integrate only licensed or otherwise authorized music and lyric sources.
